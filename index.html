Trust & Safety

Nothing goes live by accident

Every safeguard below is enforced in code and covered by automated tests — not just written down as policy.

DRY_RUN = false
Global switch. Left at its safe default, every order is simulated and logged, never sent.
+
CONFIRM_LIVE = true
A second, independent switch. Both must be flipped together — one setting alone can't go live.
+
Asset opted in
Auto-trading is opt-in per asset, empty by default — nothing trades automatically until you add it.
Minimum order floor
Hard $1 floor prevents orders too small for the exchange to accept.
Daily loss cutoff
Hard stop on total daily drawdown, enforced in code.
Max trades per day
Caps worst-case activity even if a strategy misfires.
No secrets logged
API credentials never appear in logs or error output.
